# Round 4 wordmark fonts

The fonts round 4's wordmarks and lockups were drawn from, and that rounds 5 to 8 reuse. All are
under the SIL Open Font License 1.1; each family's license is the `OFL-<Family>.txt` beside it.

| File | Family | Used by |
| --- | --- | --- |
| `Outfit[wght].ttf` | Outfit (variable) | `../3B-variations/` (V-variants), `../graph-marks/` |
| `Outfit-wght-400.ttf`, `Outfit-wght-500.ttf` | Outfit 400 and 500, static instances of the variable font | `../director/family-R1/tools/`, rounds 5 to 8 `tools/build.mjs` |
| `Figtree[wght].ttf` | Figtree (variable) | `../3B-variations/`, `../graph-marks/` |
| `Figtree-wght-400.ttf`, `Figtree-wght-600.ttf` | Figtree 400 and 600, static instances | `../child-brands/tools/`, `../director/build_index.py` (the page) |
| `Onest[wght].ttf` | Onest (variable) | `../3B-variations/`, `../graph-marks/` |
| `SourceSans3[wght].ttf` | Source Sans 3 (variable) | `../3B-variations/` |
| `DMSans[opsz,wght].ttf` | DM Sans (variable) | `../3B-variations/` |

The roughly 95 other families the font research compared are listed, with their licenses and
download links, in [../fonts-research/fonts/README.md](../fonts-research/fonts/README.md).
