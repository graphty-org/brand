# Reference marks used in round 1

Round 1's field research compared graphty's concepts with the logos of other graph tools and of the
libraries graphty is built on. Those logos belong to their projects, so this repository does not
keep copies of them. To see one, follow the link to the project's own site or brand page.

The research (`../research-field.md`) worked from each project's GitHub organization avatar
(`https://github.com/<org>.png`) and, where one exists, the official SVG from the project's site.
