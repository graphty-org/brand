2. Package names in the accent color

The rule: "graphty" is always the ink (dark on white, light on dark), and the package name ("layout", "graph-io" and so on) is in the palette's accent. The accent in the mark stays one value on both backgrounds. Text needs 4.5:1 to pass for normal-size text (WCAG 2.2, SC 1.4.3), so where the accent is fainter than that as text, the package name uses a darker step of the same hue on white, or a lighter one on dark. Three cases need it: lime and amber on white, and magenta on dark.

Lime's step #588300 and amber's #b36200 are visibly darker, olive and brown. Magenta's dark-mode step #ec3f7e is barely different from the accent. Package names in a lockup are usually large on screen, where 3:1 is enough and the raw accent would pass, but at small sizes (a README header, a sidebar) only the step passes, so the kit uses the step everywhere for one rule.
